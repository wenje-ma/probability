> **Formula 1.3.1 (The $\sigma$-algebra Generated by $X$)**<br>$\sigma\left(X\right)=\left\{\left\{X\in B\right\}:B\in\mathcal S\right\}$ is the smallest $\sigma$-algebra making $X$ measurable.

> **Definition 1.3.3 (Simple Function)**<br>A function $\phi:\Omega\to\mathbb R$ is called a simple function if $\phi\left(\omega\right)=\sum_{m=1}^{n}c_{m}\mathbf{1}_{A_{m}}\left(\omega\right)$, where $c_{m}\in\mathbb R$ and $A_{m}\in\mathcal F$.

> **Theorem 1.3.7 (Limit Operations on Random Variables)**<br>If $X_{1},X_{2},\dots$ are random variables, then $\inf_{n}X_{n}$, $\sup_{n}X_{n}$, $\limsup_{n}X_{n}$, and $\liminf_{n}X_{n}$ are all random variables. Hence $\left\{\omega:\lim_{n}X_{n}\text{ exists}\right\}=\left\{\omega:\limsup_{n}X_{n}-\liminf_{n}X_{n}=0\right\}$ is a measurable set.

## 1

Let

$$
\phi\left(\omega\right)=\sum_{m=1}^{n}c_{m}\mathbf{1}_{A_{m}}\left(\omega\right),
$$

where $c_{m}\in\mathbb R$ and $A_{m}\in\mathcal F$. Prove: the class of $\mathcal F$-measurable functions is the smallest class containing all simple functions and closed under pointwise limits.

### Solution 1

Let $\mathcal M$ be the smallest class of functions containing all simple functions and closed under pointwise limits.

First show that every function in $\mathcal M$ is measurable. Simple functions are clearly measurable (**Definition 1.3.3 (Simple Function)**); the class of measurable functions is closed under pointwise limits (by **Theorem 1.3.7 (Limit Operations on Random Variables)**, $\lim_{n}f_{n}=\limsup_{n}f_{n}$ is measurable), so by minimality of $\mathcal M$, $\mathcal M\subset\left\{\text{measurable functions}\right\}$.

Next show that every measurable function $f$ belongs to $\mathcal M$. Decompose $f=f^{+}-f^{-}$, where $f^{+}=f\vee 0$ and $f^{-}=\left(-f\right)\vee 0$. For a nonnegative measurable function $g$, construct

$$
g_{n}\left(x\right)=\frac{\left[2^{n}g\left(x\right)\right]}{2^{n}}\wedge n,
$$

where $\left[x\right]$ is the greatest integer not exceeding $x$. Each $g_{n}$ is a step simple function taking finitely many values, and $g_{n}\uparrow g$ pointwise. Now set

$$
f_{n}=f_{n}^{+}-f_{n}^{-},\qquad f_{n}^{\pm}=\frac{\left[2^{n}f^{\pm}\right]}{2^{n}}\wedge n.
$$

Each $f_{n}$ is the difference of two simple functions, hence is itself simple, so $f_{n}\in\mathcal M$; also $f_{n}\to f$ pointwise (since $f_{n}^{\pm}\to f^{\pm}$), and by closure of $\mathcal M$ under pointwise limits, $f\in\mathcal M$.

In summary, the class of measurable functions is exactly the smallest class containing simple functions and closed under pointwise limits. $\blacksquare$

## 2

Using the result of the previous problem, prove: $Y$ is measurable with respect to $\sigma\left(X\right)$ iff $Y=f\left(X\right)$ for some measurable $f:\mathbb R\to\mathbb R$.

### Solution 2

$\left(\Leftarrow\right)$ If $Y=f\left(X\right)$ and $f$ is measurable, then for any Borel set $B$,

$$
\left\{Y\in B\right\}=\left\{X\in f^{-1}\left(B\right)\right\}\in\sigma\left(X\right)
$$

(since $f^{-1}\left(B\right)\in\mathcal R$, see **Formula 1.3.1 (The $\sigma$-algebra Generated by $X$)**), so $Y$ is measurable with respect to $\sigma\left(X\right)$.

$\left(\Rightarrow\right)$ Suppose $Y$ is measurable with respect to $\sigma\left(X\right)$. First handle simple functions: if $\phi=\sum_{m}c_{m}\mathbf{1}_{B_{m}}$ is a $\sigma\left(X\right)$-measurable simple function, then $B_{m}\in\sigma\left(X\right)$, so $B_{m}=\left\{X\in C_{m}\right\}$ for some $C_{m}\in\mathcal R$, and hence

$$
\phi=\sum_{m}c_{m}\mathbf{1}_{C_{m}}\left(X\right)=g\left(X\right),\qquad g=\sum_{m}c_{m}\mathbf{1}_{C_{m}}\ \text{is measurable}.
$$

By **Solution 1**, $Y$ is the pointwise limit of $\sigma\left(X\right)$-measurable simple functions $\phi_{n}$, each of the form $\phi_{n}=g_{n}\left(X\right)$ with $g_{n}$ measurable. Set $f=\limsup_{n}g_{n}$; then $f$ is measurable (**Theorem 1.3.7 (Limit Operations on Random Variables)**), and for every $\omega$,

$$
g_{n}\left(X\left(\omega\right)\right)\to Y\left(\omega\right),
$$

so

$$
f\left(X\left(\omega\right)\right)=\limsup_{n}g_{n}\left(X\left(\omega\right)\right)=Y\left(\omega\right).
$$

That is, $Y=f\left(X\right)$. $\blacksquare$

## 3

Give a constructive proof of **Solution 2**: from

$$
\left\{m2^{-n}\le Y< \left(m+1\right)2^{-n}\right\}=\left\{X\in B_{m,n}\right\}
$$

(for some $B_{m,n}\in\mathcal R$), set $f_{n}\left(x\right)=m2^{-n}$ for $x\in B_{m,n}$, and prove that $f_{n}\left(x\right)\to f\left(x\right)$ as $n\to\infty$ and that $Y=f\left(X\right)$.

### Solution 3

Since $Y$ is measurable with respect to $\sigma\left(X\right)$, the set

$$
\left\{m2^{-n}\le Y< \left(m+1\right)2^{-n}\right\}\in\sigma\left(X\right),
$$

so there exists $B_{m,n}\in\mathcal R$ such that this set equals $\left\{X\in B_{m,n}\right\}$. For each $n$, set

$$
f_{n}\left(x\right)=\sum_{m}m2^{-n}\mathbf{1}_{B_{m,n}}\left(x\right).
$$

Each $f_{n}$ is a step simple function on $\mathbb R$, hence measurable. By construction, whenever $m2^{-n}\le Y\left(\omega\right)< \left(m+1\right)2^{-n}$, one has $f_{n}\left(X\left(\omega\right)\right)=m2^{-n}$; thus $f_{n}\left(X\right)$ is exactly $Y$ rounded down to the nearest multiple of $2^{-n}$:

$$
f_{n}\left(X\left(\omega\right)\right)\le Y\left(\omega\right)< f_{n}\left(X\left(\omega\right)\right)+2^{-n}.
$$

Hence

$$
\left|f_{n}\left(X\left(\omega\right)\right)-Y\left(\omega\right)\right|< 2^{-n}\to 0,
$$

i.e. $f_{n}\left(X\right)\to Y$ pointwise.

Set $f=\lim_{n}f_{n}$ (if it fails to converge at some points, take $\limsup$ to define it everywhere; by **Theorem 1.3.7 (Limit Operations on Random Variables)**, $f$ is measurable). Then for every $\omega$,

$$
f\left(X\left(\omega\right)\right)=\lim_{n}f_{n}\left(X\left(\omega\right)\right)=Y\left(\omega\right),
$$

i.e. $Y=f\left(X\right)$. $\blacksquare$
